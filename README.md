# 💼 Cowork – Aplicación web de gestión empresarial

Cowork es una aplicación web desarrollada en PHP cuyo objetivo es facilitar la gestión de empleados y la organización de las actividades laborales dentro de una empresa.

El proyecto centraliza diferentes procesos administrativos en una única plataforma, permitiendo gestionar usuarios, controlar jornadas laborales, organizar tareas y realizar el seguimiento de incidencias relacionadas con el entorno de trabajo.

La aplicación está desarrollada siguiendo el patrón arquitectónico MVC (Modelo-Vista-Controlador), utilizando PHP, SQL, HTML y CSS.

## 🚀 Características principales

### 👤 Gestión de usuarios
- Administración de usuarios.
- Control de acceso a la aplicación.
- Gestión de sesiones.
- Control de perfiles y permisos de usuario.

### 👥 Gestión de empleados
- Administración de la información del personal.
- Organización y consulta de los datos de los empleados.
- Gestión de información relacionada con la actividad laboral.

### ⏱️ Control de jornada laboral
- Seguimiento de la jornada laboral.
- Organización y consulta de información relacionada con los horarios de trabajo.

### 📋 Gestión de tareas e incidencias
- Administración de tareas y actividades laborales.
- Registro de incidencias.
- Seguimiento y consulta de las incidencias registradas.

## 🏗️ Arquitectura del proyecto

Cowork utiliza el patrón arquitectónico MVC (Modelo-Vista-Controlador), que permite separar las diferentes responsabilidades de la aplicación y mantener una estructura organizada.

- **Modelo:** gestión de los datos y comunicación con la base de datos.
- **Vista:** presentación de la información mediante HTML y CSS.
- **Controlador:** gestión de las peticiones y coordinación entre los modelos y las vistas.

Esta organización facilita el mantenimiento del código, la reutilización de componentes y la ampliación de funcionalidades.

## 💻 Instalación y configuración

Para ejecutar el proyecto en un entorno local es necesario disponer de:

- Servidor web compatible con PHP.
- PHP.
- MySQL o MariaDB.
- phpMyAdmin (opcional, para administrar la base de datos).

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### 2. Preparar el entorno

Coloca el proyecto dentro del directorio de tu servidor local (por ejemplo, `htdocs` si utilizas XAMPP).

### 3. Configurar la base de datos

Crea la base de datos correspondiente en MySQL y configura los datos de conexión en los archivos de configuración del proyecto.

### 4. Ejecutar la aplicación

Inicia Apache y MySQL desde XAMPP y accede al proyecto mediante el navegador:

```text
http://localhost/Cowork/
```

Nota: es necesario adaptar la configuración de conexión y la ruta de acceso según el entorno local y la estructura del proyecto.
